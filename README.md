# Faith & Beliefs

Sitio estático (HTML + CSS + JS), sin dependencias ni compilación.

## Estructura
- index.html: página principal
- css/style.css: estilos (modo claro/oscuro, responsive)
- js/app.js: contenido (ES/EN/NL completos; RO/IT/TR parciales), comparador, buscador, test
- img/: fotografías
- robots.txt, sitemap.xml: SEO básico (cambia TU-DOMINIO.com por tu dominio real)

## Publicar
- Netlify: app.netlify.com/drop y arrastra la carpeta descomprimida.
- Cloudflare Pages / Vercel: sube la carpeta como proyecto estático (sin build command).
- GitHub Pages: sube los archivos a un repositorio y activa Pages en Settings.
- Prueba en local abriendo index.html en el navegador.

## Notas
- Las fuentes se cargan desde Google Fonts; sin conexión se usan fuentes del sistema.
- Antes de publicar, revisa el contenido con fuentes académicas y oficiales.
